# Avoro IP + Traffic + Billing Finder

Userscript для [Tampermonkey](https://www.tampermonkey.net/): в списке услуг `avoro.eu/cp/clientarea.php` под каждым сервером показывает все IP, расход трафика и дату следующей оплаты.

## Установка

Откройте ссылку при установленном Tampermonkey и нажмите «Установить» / «Обновить»:

**https://raw.githubusercontent.com/dykomenko/avoro-monkey/main/avoro.user.js**

Tampermonkey сам проверяет обновления по `@updateURL` (по умолчанию раз в сутки; принудительно — «Проверить обновления» в меню расширения).

## Использование

- Клик по блоку с информацией — копирует IP (если их несколько — все, по одному на строку). Карточка услуги при этом не открывается.
- Клик по конкретному IP — копирует только его.
- `↻` — перечитать данные услуги в обход кэша.
- Меню Tampermonkey: «Обновить все услуги», «Очистить кэш».

Кэш: IP — 7 дней, трафик — 1 час, биллинг — 12 часов.

## Выпуск новой версии

1. Внести изменения в `avoro.user.js`.
2. Поднять `@version` в заголовке — без этого Tampermonkey не увидит обновление.
3. Закоммитить и запушить в `main`.
